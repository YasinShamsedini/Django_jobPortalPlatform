# 💼 Job Portal (Django)

This project supports both **employers** and **job seekers** with role-based dashboards, job management, and applications.


## Features

- Role-based login (employer & job seeker)
- Post and browse jobs
- Apply to jobs with resume upload
- Employer dashboard to manage applications
- Clean, responsive UI (Bootstrap 5)
